## Observação jurídica e técnica

O módulo gera uma **estimativa gerencial de valor**, não um laudo oficial de avaliação imobiliária.

Para uso formal, contábil, judicial, bancário ou regulatório, a empresa deve envolver profissional habilitado, metodologia formal e documentação específica.
