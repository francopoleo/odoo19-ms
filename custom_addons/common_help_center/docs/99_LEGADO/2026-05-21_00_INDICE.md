# Índice - Central de Ajuda

## Objetivo

A Central de Ajuda permite manter a documentação dos módulos Odoo dentro do próprio sistema, com artigos completos para biblioteca e artigos curtos para ajuda contextual por tela.

## Arquivos do padrão

| Arquivo | Finalidade |
|---|---|
| `01_DOCUMENTACAO_TECNICA.md` | Detalhes técnicos do módulo, models, métodos, importação e contextos |
| `02_MANUAL_USUARIO.md` | Uso funcional da Central de Ajuda |
| `03_CONFIGURACAO_INICIAL.md` | Configuração após instalação |
| `04_GUIA_TESTES.md` | Testes funcionais e técnicos |
| `05_GUIA_IMPLEMENTACAO.md` | Implantação e rotina de atualização de documentação |
| `06_TROUBLESHOOTING.md` | Erros comuns e soluções |
| `07_CHANGELOG_FUNCIONAL.md` | Alterações funcionais do módulo |
| `08_AJUDA_CONTEXTUAL.md` | Artigos contextuais curtos importáveis para o drawer |

## Conceito principal

- `docs/*.md` dos módulos são a fonte oficial versionada.
- A Central de Ajuda importa esses arquivos sem duplicar.
- Documentos completos ficam na Biblioteca.
- Ajuda contextual vem de `08_AJUDA_CONTEXTUAL.md` ou de artigos manuais associados a contextos.
- O Mapa de Contextos mostra quais telas ainda não têm ajuda.
