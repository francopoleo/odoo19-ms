# Document Core

Núcleo documental compartilhado do ERP.

Este módulo centraliza:
- cadastro de documentos
- categorias documentais
- tipos documentais
- localizações físicas
- regras de vigência, revisão e acesso

As relações com imóveis, contratos e governança são adicionadas por módulos de domínio.
