# Padrão de Mídias e Documentos

## Diferença

| Item | Uso |
| --- | --- |
| Documento | Arquivo formal, validável, com categoria, tipo, validade ou revisão. |
| Mídia | Foto, imagem, scan ou arquivo visual ligado a imóvel, vistoria, manutenção ou galeria. |
| Galeria do imóvel | Fotos comerciais/publicáveis e ordenadas para uso no site. |
| Evidência | Foto ou arquivo ligado a vistoria/manutenção. |

## Regra

Uma mídia não deve ser simultaneamente foto e documento. A classificação correta evita confusão na galeria, vistoria e manutenção.
