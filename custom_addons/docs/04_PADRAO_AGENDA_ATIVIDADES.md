# Padrão de Agenda Geral e Atividades

## Diferença central

| Item | Usar quando | Não usar para |
| --- | --- | --- |
| Atividade | Cobrar, lembrar, pedir ação individual | Compromissos operacionais estruturados |
| Agenda Geral | Vistorias, manutenções, prazos formais, pendências e marcos | Tarefas pequenas ou comunicação informal |
| Calendário Odoo | Reuniões nativas e pessoais | Vistorias/manutenções/documentos operacionais |

## Exemplo

### Caso novo de governança

| Campo | Valor |
| --- | --- |
| Caso | Reclamação de infiltração |
| Prazo de resposta | 22/05 |
| Prazo de resolução | 04/06 |
| Responsável | João |

Resultado na Agenda Geral:

- Prazo de Resposta - Reclamação de infiltração.
- Prazo de Resolução - Reclamação de infiltração.

Atividades:

- Tarefas individuais para cobrar análise, resposta ou validação.
